# SYNCCORE · Station

kein Anfang  
kein Ende  
aber wir streben.

SYNCCORE ist der Kernpunkt.  
Eine Station.  
Fluid.  
Offen.  
Bereit.

## Bau-Steine der Darstellung

### [up.html](ca://s?q=up_html_Erklärung)
Der obere Resonanzpunkt.  
Er zeigt die Bewegung nach oben.  
Ein leichter Impuls.  
Ein Streben.

### [left.html](ca://s?q=left_html_Erklärung)
Der linke Ruhepunkt.  
Er zeigt die seitliche Verschiebung.  
Ein Ausgleich.  
Eine Haltung.

Diese beiden Bau-Steine helfen der Station,  
ihre Lage sichtbar zu machen,  
ohne Technik,  
ohne Achsen,  
ohne Operatoren.

Sie sind Darstellungen.  
Keine Funktionen.  
Keine Systeme.  
Nur Punkte.  
Nur Formen.
